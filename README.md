## Executive Overview

A modern, accessible software engineering portfolio website designed and developed for Amulya M.G. Built with React 18 and Tailwind CSS, the platform highlights machine learning repositories, computer vision implementations, verified academic achievements, and an embedded ATS-friendly resume download.

---

## Core Capabilities & Features

- **Curated Machine Learning Portfolio:** Highlighting computer vision, deep learning, and data engineering projects.
- **Direct Resume Download:** Embedded verified PDF download (`public/ATS Friendly Resume Amulya MG.pdf`).
- **Responsive Dark/Light Aesthetics:** Smooth mobile-first layout optimized for recruiter review.
- **Social & Professional Integration:** Direct verified links to GitHub and LinkedIn profiles.

## Setup & Installation

```bash
git clone https://github.com/StratagemVX/Amulya-portfolio-webpage.git
cd Amulya-portfolio-webpage
npm install
npm run dev
```
