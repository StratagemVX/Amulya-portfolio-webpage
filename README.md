# Amulya M.G — AI & ML Developer Portfolio

> Modern, responsive engineering portfolio website highlighting machine learning models, computer vision systems, academic credentials, and verified achievements.

---

## 1. Project Title
**Amulya M.G Portfolio** (`Amulya-portfolio-webpage`) — Machine Learning & AI Developer Portfolio.

## 2. Project Overview
A production-ready personal developer website showcasing the projects, technical competencies, and academic background of Amulya M.G. Built with modern React and Tailwind CSS, it features dark-mode aesthetics, smooth component transitions, project cards, and a direct download link for an ATS-optimized resume.

## 3. Key Features
- **Curated Project Showcase:** Highlights artificial intelligence, deep learning, and data analytics work.
- **ATS Resume Download:** Verified PDF resume download embedded directly in `public/`.
- **Responsive Layout:** Optimized for mobile phones, tablets, and widescreen desktop monitors.
- **Interactive Contact Section:** Form inputs and social profile links (LinkedIn, GitHub).

## 4. Technology Stack
- **Frontend:** React 18, Vite, TypeScript, Tailwind CSS, Lucide React, shadcn/ui

## 5. Installation Instructions
```bash
git clone https://github.com/StratagemVX/Amulya-portfolio-webpage.git
cd Amulya-portfolio-webpage
npm install
npm run dev
```
